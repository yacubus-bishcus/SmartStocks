# StockApp
This program allows the user to run various financial models on a group of user input stocks as well as any random tickers researched. The program offers various input options and various outputs. The code is designed to be modular where additional financial models can be easily added either by using Models.py or the user's own Models module/classes. The primary function is to generate a monthly report of requested and/or researched stocks in either word or pdf format and export that report to any given email.
